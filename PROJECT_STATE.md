## 5. BACKLOG

Из PRODUCT.md 18 «Не входит в MVP»:
- Мобильное приложение для поставщика.
- Кросс-номера и автоматический подбор аналогов по номерам.
- Запись на услуги по слотам и календарю.
- Автоподтверждение совместимости по совпадению источников.
- Автоматическая блокировка поставщика по рейтингу; блокировка пользователя после трёх неявок.
- Платное продвижение поставщиков.
- Несколько складов одного поставщика (место заложено: `supplier_location`).
- Расширенная аналитика поставщика.
- Роли и права сотрудников поставщика (место заложено: единый предикат прав).
- Офлайн сверх активных заявок.
- Оплата подписки пользователя картой напрямую — пересмотр при росте цены и числа подписчиков.
- Хранение VIN и госномера.
- Фиксация факта предоплаты по заявке под заказ.
- Аттестация устройства для гостевого лимита.

Идеи, всплывшие в обсуждении, не принятые:
- Локальный список отсканированных кодов в PWA с отправкой при появлении сети (ARCHITECTURE 3.6.4, вариант B) — дешёвое улучшение после этапа B.
- Показ поставщику ориентировочной стоимости его уведомлений.
