Структурированные JSON-логи с requestId, без тел запросов и секретов. CI: format, lint, typecheck, unit, интеграционные тесты на реальной PostgreSQL (Testcontainers) с циклом миграций, build, проверка корректного завершения worker по SIGTERM на Linux; запуск только на push в `main` и pull request, устаревшие прогоны отменяются. Зелёный прогон подтверждён: run 35141135754.

**TASK-001 — монорепозиторий.** Монорепозиторий (pnpm workspaces + Turborepo): `apps/api` (NestJS, health-эндпоинт, отдельный worker-процесс с корректным завершением), `apps/mobile` (Expo, Metro запускается), `apps/admin-web` и `apps/supplier-web` (Vite + React, живой запрос к API), пакеты `contracts` (демо-схема, используется сервером и клиентом), `domain` (нормализация артикула с тестами), `ui`, `i18n`, `config`. Docker Compose для dev: PostgreSQL, Redis, Meilisearch, MinIO. Линт запрещает импорт через границы пакетов. CI на GitHub Actions: format, lint, typecheck, test, build — зелёный. CLAUDE.md, блок «0. Проект» — фактические команды.

Бизнес-логики, модели данных и миграций нет. Документы проекта остаются в корне репозитория (не в `docs/`), это зафиксировано в ARCHITECTURE.md.

- Офлайн сверх активных заявок.

- Хранение VIN и госномера.
- Фиксация факта предоплаты по заявке под заказ.
- Аттестация устройства для гостевого лимита.

- Локальный список отсканированных кодов в PWA с отправкой при появлении сети (ARCHITECTURE 3.6.4, вариант B) — дешёвое улучшение после этапа B.
