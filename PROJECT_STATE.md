Refresh-токен в базе не хранится ни в каком виде — только случайное зерно и номер поколения, токен выводится с секретом сервера. Список сессий — только свои, текущая отмечена, IP сокращён до `/24`; чужая сессия неотличима от несуществующей. Мгновенный отзыв: каждый защищённый запрос проверяет строку сессии в PostgreSQL (чёрного списка в Redis нет); при недоступном Redis отозванные сессии отклоняются, действующие работают, не работает только обмен токена (503, повтор); при недоступной PostgreSQL защищённые маршруты отвечают 503. Механика cookie-сессий кабинета и админки готова (HttpOnly, Secure, SameSite=Strict, cookie уходит только на обмен и только с `Origin` своего веб-клиента), выдача закрыта до TASK-006: 403 `SESSION_KIND_UNAVAILABLE` до проверки кода, код не расходуется. Вид сессии выбирает `X-Client`; без заголовка — мобильная, наименее привилегированная. CORS — только домены кабинета и админки из конфигурации (`SUPPLIER_WEB_ORIGINS`, `ADMIN_WEB_ORIGINS`), чужой `Origin` получает 403 `ORIGIN_NOT_ALLOWED`; запросы без `Origin` работают; долг T-1 закрыт. Токены не попадают в журнал и ответы (тест перехвата всего вывода процесса); ошибки запросов к базе пишутся без значений параметров. Правило коммитов D-024 внесено в CLAUDE.md. ## 5. BACKLOG

- **Проверка владения автомобилем по техпаспорту** (решение Product Owner 26.09.2026, направление): добавить автомобиль «просто так» будет нельзя — потребуется скан техпаспорта. Сейчас в PRODUCT техпаспорт описан только как способ ввода данных (распознавание, этап D, фото удаляется после подтверждения, VIN и госномер не хранятся), правила проверки владения нет. Требует продуктовой проработки: что считается подтверждением, что хранится, что с персональными данными и с теми, кто ездит по доверенности.
- **Поиск запчастей по VIN через OEM-каталог** (направление Product Owner от 27.09.2026, главное обоснование хранения VIN в D-064): по VIN определяется конкретный автомобиль в каталоге производителя, оттуда берутся **точные оригинальные номера** деталей именно для этой машины и схемы узлов. Сильнее, чем декодирование спецификации. **Что придётся решить:** доступ к каталогам лицензионный и платный (Laximo и подобные; у TecDoc привязка к типу автомобиля, а не к VIN), и это **второй источник истины о совместимости** рядом с нашим справочником, где за совместимость отвечает администратор (D-029, на этом построен весь расчёт TASK-015): кто главнее и кто кого проверяет.
- **Декодирование спецификации по VIN** (D-064 отложил): платные декодеры дают мало сверх техпаспорта, а для китайских марок ненадёжны. Вернуться, если окажется, что техпаспорта не хватает для точной комплектации.
- **Что ограничивать автомобилям с отметкой «документ не подтверждён»** (D-064): запрет заявок, лимит просмотров или только сигнал администратору — решить на данных, когда распознавание заработает.
- **Платный доступ по автомобилям** (решение Product Owner 26.09.2026, направление): по подписке доступен один автомобиль, каждый следующий — отдельная оплата. Влияет на EPIC-14 (подписки) и на гараж; требует проработки вместе с ценой подписки.
