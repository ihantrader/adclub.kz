## Technical Decisions
- Гостевой гараж — только на устройстве; сервер получает автомобиль параметрами запроса. Перенос идемпотентен по `client_id`, дубли определяются по `modification_id` либо по всем заполненным у обеих записей полям, серверная запись дополняется пустыми полями.
- Счётчик гостевого лимита — только на сервере, инкремент до вызова провайдера условным обновлением; лимит по IP и дневной бюджет гостей как потолок; усиление аттестацией — настройкой.
- Офлайн-кэш: только активные заявки, шифрование ключом из Keychain/Keystore, полная замена ответом сервера, никаких офлайн-действий пользователя.
- Позднее закрытие — отдельный переход `close_late` в окне настройки; правило по рейтингу и дисциплине — на выбор PO (вопрос 20.18).
- Сотрудники: одна учётная запись на телефон, членства как контексты сессий, отзыв через чёрный список Redis для сессий кабинета, роли — через один предикат.
- Пересмотр рекомендаций 0.1: единственное изменение — роли сотрудников `owner|staff` заменены на единственную роль `member` (PRODUCT 12.6 «все равноправны»); выбор Expo, PWA и схемы сессий проверен и сохранён, обоснование в 3.6.5 и 8.3.
