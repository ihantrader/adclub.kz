# TASK-014 — Справочник автомобилей и импорт

Модель: Opus 5, High

## Цель

Появляется справочник автомобилей: марка → модель → поколение (годы) → модификация (кузов, двигатель, КПП, привод). Администратор ведёт его вручную и пополняет импортом файла, видя отчёт до применения. Клиенты получают данные для пошагового выбора автомобиля в гараже.

## Требования

### 1. Модель

- **Марка** (название, другие написания), **модель** (марка, название, другие написания), **поколение** (модель, название, годы выпуска), **модификация** (поколение, кузов, двигатель, КПП, привод, годы, рынок, источник, статус).
- **Справочные списки:** кузов, КПП, привод — ведёт администратор, названия kk/ru/en (это не имена собственные).
- **Двигатель:** код, объём, топливо, мощность, другие написания; один двигатель используется многими модификациями.
- **Годы:** год начала обязателен, год окончания может отсутствовать (модель выпускается сейчас); год окончания не раньше года начала; годы модификации укладываются в годы поколения.
- **Рынок:** казахстанский или общий — чтобы отличать местные комплектации (PRODUCT 7.7).
- **Уникальность:** марка по названию и написаниям; модель — в пределах марки; поколение — в пределах модели; модификация — по набору «поколение + кузов + двигатель + КПП + привод + годы». Совпадение — понятная ошибка со ссылкой на существующую запись.
- **Архивирование вместо удаления** на всех уровнях: архивная запись не предлагается для нового выбора, но сохраняется у тех, кто её уже выбрал. Архивирование верхнего уровня скрывает нижние.
- **Источник записи** (вручную / импорт) фиксируется.

### 2. Ведение администратором

- Создание, правка, архивирование и восстановление на всех уровнях; перенос модели к другой марке и поколения к другой модели — если это понадобится, поведение описать.
- Одновременная правка не перезаписывает чужое изменение молча (версии, как в справочнике товаров).
- Каждое изменение — в журнал действий в той же транзакции.
- Поиск и постраничный вывод по маркам, моделям, поколениям и модификациям с отборами (марка, модель, годы, рынок, состояние).
- Только в контексте `admin`.

### 3. Импорт файлом

- **Шаблон.** Администратор получает шаблон файла с описанием колонок и примером строки.
- **Загрузка и разбор.** Принимается табличный файл распространённого формата; содержимое проверяется фактически, как в TASK-013 (не по расширению). Предел размера и предел числа строк — настройки.
- **Отчёт до применения** (SCREENS A-CAR-02): сколько строк будет добавлено, сколько обновлено, сколько отклонено, с номерами строк и причинами. Ничего не меняется, пока администратор не подтвердит.
- **Применение** по подтверждённому отчёту: строки применяются по правилам требования 1; повторный импорт того же файла не создаёт дублей (идемпотентность по содержимому строки).
- **Частичные данные:** строка без части полей (например, без мощности) принимается, если хватает обязательных; неизвестные значения справочных списков (кузов, КПП, привод, топливо) — ошибка строки с понятной причиной, а не молчаливое создание.
- **Ошибки:** файл не разобран, нет обязательных колонок, лишние колонки, пустой файл, кодировка, разделители — понятные ошибки, не 500.
- **Большой файл** обрабатывается фоновой задачей: администратор видит состояние (разбирается / отчёт готов / применяется / применён / отклонён / ошибка) и может отменить до применения. Предельное время и размер пакета — настройки.
- **История импортов** с отчётами сохраняется; кто и когда загрузил и применил — в журнале действий.

### 4. Данные для клиентов

- Маршруты для пошагового выбора автомобиля (M-GAR-03): марки → модели марки → поколения модели → модификации поколения, только активные записи, с названиями справочных списков на языке запроса и откатом на русский.
- Доступно без входа (гостевой режим) и с любой сессией; кэширование как у справочника товаров.
- Ответы не отдают архивные записи; несуществующее и архивное — одинаковый 404.

### 5. Данные для разработки

- Команда заполнения dev-базы небольшим набором: марка Geely с несколькими моделями, поколениями и модификациями казахстанского рынка, плюс одна другая марка; справочные списки кузовов, КПП, приводов, топлива. Только development и тесты, повторный запуск без дублей. Данные — правдоподобные, но черновые; в отчёте отметить, что они не выверены по официальным источникам.
- Пример файла импорта для проверки — в репозитории как данные.

### 6. Контракт и документация

- Маршруты, схемы, коды ошибок — в `contracts`, OpenAPI, `@adclub/api-client`; изменение аддитивное.
- ARCHITECTURE.md: подраздел решений 4.x (модель, уникальность, импорт и его состояния, идемпотентность, кэширование клиентских ответов), уточнение 5.3 и 14, версия и история.
- CLAUDE.md, блок 0: как заполнить автомобили в dev, как импортировать файл и посмотреть отчёт.

## Бизнес-правила

- Справочник автомобилей ведёт только администратор.
- Удаления нет — архивирование; выбранное пользователями не пропадает.
- Импорт ничего не меняет до подтверждения администратором.
- Казахстанские комплектации отличаются от общих и различимы в данных.
- Имена собственные (марки, модели, коды двигателей) не переводятся.

## Edge cases

- Импорт: 10 000 строк; дубли внутри файла; строка ссылается на несуществующее поколение; годы модификации выходят за годы поколения; неизвестный кузов; та же модель с другим написанием марки («Geely» и «GEELY»).
- Повторное применение одного отчёта; применение отчёта, устаревшего из-за ручных правок; отмена импорта после разбора.
- Архивирование марки с активными моделями; восстановление модели под архивной маркой.
- Модификация без года окончания; поколение, которое ещё выпускается.
- Одновременная правка одной записи двумя администраторами.
- Клиентский запрос модификаций поколения без модификаций; архивная марка по прямой ссылке.
- Мобильная сессия и сессия кабинета вызывают маршруты администратора.

## Acceptance Criteria

- **AC-1.** Модель по требованию 1 создана; правила годов, уникальности и архивирования держатся сервером и, где применимо, базой — тесты.
- **AC-2.** Администратор ведёт все уровни, одновременная правка не перезаписывает чужое, каждое изменение — в журнале в той же транзакции — тесты.
- **AC-3.** Поиск и постраничный вывод с отборами работают без пропусков — тесты.
- **AC-4.** Импорт: шаблон, разбор, отчёт до применения с числами и номерами ошибочных строк, подтверждение, применение, отмена; ничего не меняется без подтверждения — тесты.
- **AC-5.** Повторный импорт того же файла не создаёт дублей; применение устаревшего отчёта не портит данные — тесты.
- **AC-6.** Ошибки файла (не разобран, нет колонок, пустой, слишком большой, слишком много строк) дают понятные коды — тесты.
- **AC-7.** Большой файл обрабатывается фоновой задачей, состояние видно, отмена до применения работает — тест.
- **AC-8.** Клиентские маршруты пошагового выбора доступны гостю и любой сессии, отдают только активное, с языком и откатом на русский, кэшируются — тесты.
- **AC-9.** Маршруты администратора — только контекст `admin` (матрица предиката).
- **AC-10.** Dev-заполнение и пример файла импорта работают, повторный запуск без дублей, вне development/test недоступно.
- **AC-11.** Контракт, OpenAPI, клиент — аддитивно, совместимость без трейлера; миграции обратимы; таблицы в сверке схемы; существующие тесты не ослаблены; перехват вывода чист.
- **AC-12.** Коммиты по D-024 с составом в отчёте; CI на `main` зелёный с первой попытки, включая коммит с отчётом (номер и статус через `gh`).
- **AC-13.** ARCHITECTURE.md (4.x, 5.3, 14, версия, история) и CLAUDE.md (блок 0) обновлены.

## Что должно реально работать

В dev, запросами к API:

- Заполнить автомобили → гость проходит выбор: марки → модели Geely → поколения → модификации, на русском и на казахском (названия кузовов и КПП переведены, марки и коды двигателей — нет).
- Администратор добавляет модификацию казахстанского рынка → она появляется в выборе.
- Загрузить пример файла импорта → отчёт «добавится N, обновится M, ошибок K» с номерами строк → применить → числа совпали → загрузить тот же файл снова → «добавится 0, обновится N».
- Загрузить файл с ошибочными строками (неизвестный кузов, годы вне поколения, дубль внутри файла) → строки отклонены с причинами, остальные применились.
- Отменить импорт после отчёта → ничего не изменилось.
- Архивировать марку → её моделей нет в выборе; прямой запрос архивной марки → 404.
