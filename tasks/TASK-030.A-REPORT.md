## Technical Decisions

Внесены в ARCHITECTURE.md 4.43 (I456–I465), кратко:

- **Значки — пути из SVG в репозитории, а не пакет-компонент** (I456–I457). Пакет `@phosphor-icons/core` на этой машине не устанавливается (`ERR_PNPM_EPERM` при распаковке ~9 000 файлов, дважды) — и он не нужен: нужные SVG лежат в `design/icons/phosphor` с лицензией MIT, генератор работает без зависимостей, бандл получает только используемые глифы. Новый глиф — `npm pack @phosphor-icons/core` и `pnpm icons --vendor …`.
- **Коды категорий контракта не тронуты** (I458): это смысловые коды данных, глиф выбирается в `icons.mjs`.
- **«Первая плитка широкая» — правило вёрстки** `tileRows` по порядку данных; ни одного кода категории в экране (I459).
- **Сегменты** — по ширине подписи, в одну строку, шрифт подписи до 120 % (как у вкладок), при нехватке места — прокрутка вбок; пояснение порядка — строка постоянной высоты (I460).
- **Навигаторы** — приложение, а при отказе системы — веб того же сервиса; без `canOpenURL`, поэтому ни Expo Go, ни сборке для сторов не нужны `LSApplicationQueriesSchemes`/`<queries>` (I462).
- **Фото в заявке** — фото позиции справочника на момент запроса, аддитивно только в карточках, старая копия на устройстве читается с `photo: null` (I463).

## Чек-лист ручной проверки на телефоне (Expo Go)

Подготовка: API и worker запущены, `pnpm --filter api operator dev:catalog:arrange` выполнен (или база свежая), `pnpm --filter mobile start`.

1. **Значки:** нижние вкладки, профиль, гараж, шапка каталога — тонкие линии Phosphor, нигде нет старых значков Tabler; Профиль → «Витрина компонентов (dev)» → «Значки категорий»: посмотреть девять «нарисован» и утвердить или заменить.
2. **Light на 16:** витрина → «Light и Regular на 16» — решить, оставить ли Light на мелких значках (метки, строки списков).
3. **Шапка каталога:** две равные кнопки «Geely Atlas 2023 ▾» и «Алматы ▾» в одну строку; добавить автомобиль с длинным именем (Chery Tiggo 7 Pro 2024) — текст ужимается/многоточие, без переноса.
4. **Плитки:** «Расходники» — первая широкая, остальные по две, значки по центру на круглой подложке, у «Салона» руль; по-казахски «Шығын материалдары» не обрезается.
5. **Сортировка по-казахски:** Профиль → язык «Қазақша» → Тежегіштер → Тежегіш қалыптары: «Ұсынамыз · Арзанырақ · Тезірек» в одну строку, под ними строка «Алдымен — …» меняется при выборе, список не прыгает.
6. **Крупный шрифт:** в настройках телефона — самый крупный шрифт; первый запуск (удалить данные Expo Go) прокручивается, кнопки не налезают; сортировка остаётся в одну строку.
7. **Экран заявки (самовывоз):** «Где забрать», фото колодок (если загружено), «Маршрут | Позвонить» пополам в одну строку (ru и kk).
