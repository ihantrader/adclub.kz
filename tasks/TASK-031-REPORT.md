## Technical Decisions
Внесены в `ARCHITECTURE.md` 4.47 (I491–I503):
- Адреса — собственный маленький маршрутизатор, ссылки в навигации; вход показывается поверх запрошенной страницы (I491).
- Токены: refresh — только cookie, access — только память; что означает каждый ответ обмена (I492).
- Один обмен на одновременные запросы; несколько вкладок — замок Web Locks, рассылка токена по BroadcastChannel, заимствование живого токена при открытии; страховка — серверный допуск 60 с (I493–I494).
- Выход только по слову сервера, как в мобильном I438 (I495).
- Смена компании сначала убирает всё прежнее и перемонтирует страницы (I496).
- «Нет сети» + проба `/health` раз в 10 с (I497).
- Свой service worker «страница — сеть сначала, оболочка — кэш», вопрос новому worker'у «есть ли мой скрипт в новой версии» для «Обновить» (I498).
- S-INST-01, язык уведомлений по умолчанию, версии форм компании (I499–I501).
- Исправлен `sideEffects` `@adclub/ui` (I502).
- `pnpm dev:lan`: локальный CA с ограничением имён (только частные сети и localhost), сертификат на 397 дней, TLS-прокси к API, страница-помощник (I503).

2. Вход `+77055550101` → код → кабинет «Автомаркет»; сразу показывается «Установить на экран» со шагами «Поделиться → На экран „Домой“».
3. Неверный код — «Неверный код. Осталось попыток: N»; «Отправить по SMS» — заголовок «Введите код из SMS».
4. «Поделиться → На экран „Домой“» → значок «AD Кабинет» на экране; открыть оттуда — без адресной строки, **нужно войти ещё раз** (свои cookie у установленного кабинета).
5. «Ещё → Сотрудники → Добавить сотрудника» (имя, номер `+7 705 …`) → «Приглашение отправлено в WhatsApp»; включить коллеге «Получает уведомления», выбрать «Қазақша».
6. «Ещё → Компания» → «Часы работы»: изменить, «Сохранить» → «Сохранено»; добавить нерабочую дату; прошедшую выбрать нельзя.
7. Закрыть кабинет (смахнуть), открыть через час/день — сразу внутри, без входа.
8. Включить авиарежим, открыть кабинет с экрана «Домой» — оболочка с «Нет сети», не белый экран; выключить авиарежим — через несколько секунд всё работает.
9. Настройки iOS → Универсальный доступ → Увеличенный текст / «Aa» в Safari 200 % — ничего не налезает.
10. С другого устройства удалить этого сотрудника (вторым сотрудником в «Сотрудниках» или `pnpm --filter api operator dev:member:remove <memberId>`) — на iPhone следующий переход: «Доступ к кабинету закрыт. Обратитесь к коллегам или администратору клуба».
11. «Мои настройки → Оформление: Тёмная», «Язык интерфейса: Қазақша» — применяется сразу; казахские тексты не обрезаны.

**Android (Chrome)**
1–3, 5–8, 10–11 — как для iPhone.
4. «Ещё → Установить на экран» → «Установить» → системный запрос Chrome → значок на экране; открывается как приложение; после установки пункт «Установить на экран» исчезает.
9. Настройки Android → Экран → Размер шрифта максимальный (и Chrome → Специальные возможности → Масштабирование текста 200 %) — без наложений.

**Компьютер (Chrome)**
- Ширина ≥ 1024 — боковое меню; две вкладки кабинета открыты час с коротким сроком токена (`settings:set session_access_token_ttl_seconds 60`) — обе работают, ни одна не просит входа.
