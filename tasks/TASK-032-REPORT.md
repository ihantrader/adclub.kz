## Result
- **«Предложения» в кабинете** (`/offers`, S-OFF-01): вкладки «В продаже · N» / «Снятые · N», поиск по своим предложениям (название, артикул, свой артикул), отборы «В наличии» / «Под заказ» / «Без фото», подгрузка страниц при прокрутке. На телефоне — карточки, от 1024 — таблица. В строке: название, бренд и артикул, «Без фото», **«Активные заявки: N»**, значки самовывоза и доставки, **«Не видно клиентам: …»** с причиной сервера (часы точки — ссылка на «Компанию»; при такой причине — один баннер над списком).

Конфликт обычной правки — свежие значения коллеги в тексте, введённое остаётся в поле. Пределы цены и срока — у поля, словами кабинета («Цена — от 1 до 100 000 000 ₸»).
- **Снять / вернуть**: при активных заявках — «По этому предложению N активных заявок — их нужно выполнить», снятие разрешено; «Вернуть в продажу» открывает карточку с «Проверьте цену…» и курсором в цене; позиция ушла из справочника — понятный отказ.
- **Поиск позиции** (`/offers/search`, S-OFF-02): только по запросу от 3 букв/цифр (меньше — подсказка, без запроса), артикул в любом написании, «Уже в ваших предложениях» ведёт в предложение, «Позиции нет в справочнике. Напишите администратору клуба», 429 — «Слишком много поисков, подождите N с».
- **Новое предложение и карточка** (`/offers/new`, `/offers/<id>`, S-OFF-03): одна форма; позиция — только чтение; цена, наличие, срок, самовывоз/доставка, гарантия (месяцы или текст), свой артикул и название; «Клиент увидит: Самовывоз — завтра, 6 октября · Доставка — до 6 октября» по `offer-receipt-preview`; без часов — D-060 со ссылкой; отказы сервера у полей (самовывоз без адреса, контакты в гарантии, пределы, предложение уже есть — ссылка на него). Карточка: состояние витрины, «Активные заявки», снять/вернуть; адрес переживает перезагрузку.
- **«Доставка по умолчанию для новых предложений»** (S-COMP-01): колонка и поле карточки компании с версией и журналом, переключатель на «Компании», форма нового предложения берёт его.

## Known Issues / Risks
- **Мобильное приложение:** положение сообщения на iPhone/Android проверено только под react-native-web; `measureInWindow` на нативных платформах и фокус экранов (`NavigationContext`) — за проверкой Product Owner.
- **Окно браузера в фоне:** правка в строке сохраняется по уходу из поля; если вкладка закрыта с введённым и не покинутым полем — значение не сохранится (как у обычных форм).
- На 1024 таблица предложений прокручивается внутри рамки (~80 px).
- **Изменения dev-данных:** «Шины Юг» — новое предложение Shell Helix HX8 (9 700 ₸, только доставка, гарантия «12 месяцев по чеку»), «Доставка по умолчанию» включена; у колодок Geely цена возвращена 13 500; TRW снят и возвращён (12 500). В гараже приложения-в-браузере — Geely Atlas 2023 и Coolray 2024 (основной). Временные настройки возвращены.
- **Процессы:** по D-065 заменил чужой `tsx watch` API на `:3000` своим из `launch.json` (тот же код) — `pnpm dev:lan` (запущен до сессии, порты 3443/5443/5480) не трогал, он проксирует на мой API. После завершения сессии API может остановиться — тогда для телефона перезапустить `pnpm dev` (или `pnpm --filter api dev`).

Кабинет — `https://<адрес>:5443`, код входа — `http://localhost:3000/dev/login-codes` на машине. **Кабинет на iPhone собирается заново командой `pnpm dev:lan` (без `--no-build`)** — иначе на телефоне останется сборка TASK-031.
