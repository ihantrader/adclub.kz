# TASK REPORT — TASK-032.A

## Status
COMPLETED — проверка на iPhone и в Expo Go остаётся за Product Owner (список ниже); CI на main — см. «Verification».

## Result
Одно правило «Загрузка без мигания» (DESIGN 7.6, D-069) работает в кабинете поставщика, веб-компонентах админки и мобильном приложении:

- индикатор (каркас, полоса, спиннер кнопки) появляется только после 300 мс ожидания и держится не меньше 500 мс; быстрый ответ показывается сразу, без индикатора;
- при повторной загрузке (вкладка, отбор, поиск, сортировка, возврат на экран) прежнее содержимое остаётся на месте, приглушённое до 0,5 под тонкой полосой, и сменяется новым растворением 150 мс; каркас — только при первой загрузке, его место занято с самого начала (высота не прыгает);
- из нескольких быстрых запросов показывается только последний;
- ошибка повторной загрузки не стирает прежнее содержимое — сверху баннер с «Повторить»;
- страницы кабинета, шаги входа и экраны «старт → вход → кабинет» сменяются растворением 150 мс; шапка, вкладки и боковое меню не перерисовываются;
- смена компании — рамка остаётся с новым названием, данные прежней компании исчезают сразу, страница растворяется в загрузку новой; заставка «Starting» больше не вспыхивает;
- при «Уменьшить движение» растворений нет, содержимое просто сменяется; задержка индикатора остаётся;
- недостающий ключ текста больше не роняет кабинет: показывается сам ключ, в dev — предупреждение в консоли.

## Technical Decisions
Внесены в ARCHITECTURE 4.49:
- I517 — правило в `ui-core` рядом с `motionPlan`, одно на все клиенты; платформы только оборачивают `createLoadingGate` в хуки.
- I518 — «Уменьшить движение» снимает растворение смены (уже, чем общее правило движения — так сказано в DESIGN 7.6), задержка остаётся.
- I519 — ответ держится вместе с индикатором (смена содержимого и уход полосы — один кадр); быстрый ответ не задерживается. Исключение — общая копия активных заявок в приложении: там по правилу только полоса.
- I521 — старое содержимое под видимой полосой неактивно (`inert`) там, где действие опасно: правка в строках «Моих предложений», переключатели «Сотрудников».
- I522 — смена компании через состояние `loading` с `switchingTo`; попутно исправлено: прерванная подгрузка страницы оставляла «Показать ещё» в загрузке навсегда.
- I524 — недостающий ключ текста.
