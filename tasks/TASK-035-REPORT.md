## Deviations
- **«Без перевода» на главной:** карточка теперь показывает число **позиций** (`itemsWithoutTranslation`) — то, что открывает список; прежнее число **текстов** всего справочника (категории, характеристики, варианты) — в подписи карточки. Иначе требование «число строк совпадает со счётчиком» выполнить нельзя: список — список позиций.
- **«Есть предложения»** считает предложения «в продаже» (`active` и `suspended`, как вкладка «В продаже» кабинета), а не только видимые на витрине — видимость с причинами показана во вкладке «Предложения».
- Перетаскивания в дереве нет — порядок стрелками (задача допускает «перетаскиванием или стрелками»).

## Known Issues / Risks
- История позиции (`?itemId=`) отбирает записи журнала по `before/after ->> 'itemId'` для фото и совместимости — без отдельного индекса; на большом журнале запрос может замедлиться (сейчас журнал мал).
- Список брендов в отборе «Позиций» и списки марок, моделей, двигателей в выборе автомобиля берут первые 100 записей — для dev-данных достаточно; при росте справочника нужен поиск в этих выпадающих списках.
- После изменения `packages/contracts` dev-сервер админки нужно перезапускать с удалением `node_modules/.vite` (особенность пребандла Vite для связанных пакетов).

## Проверки для Product Owner в браузере
Подготовка: `docker compose -f infra/docker/compose.dev.yml up -d`, `pnpm --filter api migrate`, `pnpm --filter api operator dev:compatibility:seed`, `pnpm --filter api operator dev:suppliers:seed`; запустить `api`, `worker`, `admin-web` (`.claude/launch.json` или `pnpm dev` + `pnpm --filter api worker`); войти в `http://localhost:5174`.
1. **Главная → «Без фото»** — открывается список позиций с отбором «Без фото», «Всего» совпадает с числом на карточке. То же для «Неполные», «Без совместимости», «Без перевода».
2. **Фото колодок:** «Справочник» → «Позиции» → колодки → «Фото» → выбрать JPEG → «Загрузить» → «Подтвердить». Повторно тот же файл — «Это фото у позиции уже есть». Файл не-картинку — «Это не изображение».
3. **Казахское название «Тормозных колодок»:** «Категории» → «Тормоза» → «Тормозные колодки» → «Изменить» → поле «Казахский» → «Сохранить»; в шапке узла — «вручную».
4. **Совместимость:** колодки Geely 04465-0K090 → «Совместимость» → «Добавить запись» → марка Geely, модель (например Coolray), основание → «Сохранить»; ниже «Проверить на автомобиле» → Geely, та же модель → «Проверить» — «Подходит»; другая модель — «Не подходит».
5. **Через минуту в приложении** (`pnpm --filter mobile exec expo start --web --port 8082` или телефон): автомобиль той же модели → «Тормоза» → «Тормозные колодки» — колодки с отметкой «Подходит» и фото; язык «Қазақша» — «Тежегіш …» с новым названием.
6. **Характеристика и дозаполнение:** у «Тормозных колодок» → «Добавить характеристику» («Материал», «Список») → баннер «У N позиций значение будет пустым» → «Варианты» (добавить 2–3) → «Дозаполнить» → выбрать значения → «Сохранить».
7. **Конфликт:** та же страница во второй вкладке — переставить узел стрелкой, затем в первой — «Эти данные только что изменил …».
8. **Предложение поставщика:** войти в кабинет сотрудником «Автомаркета», предложить совместимость позиции (или `POST /supplier/catalog/items/<id>/compatibility-proposals`) → «Справочник» → «Предложения совместимости» → позиция → «Подтвердить» / «С правкой» / «Отклонить».
9. **Журнал:** «Журнал» → отбор «Позиция» или «Вариант характеристики» → ссылка открывает карточку или дерево с выделенной строкой.
10. **Тёмная тема** (переключатель в шапке) и окно 1024 px — без горизонтальной прокрутки страницы.
