# TASK-035.B — Админка: справочник автомобилей и импорт файлом

Модель: Opus 5.5, Medium

## Цель

От справочника автомобилей зависит всё приложение: без машины нет каталога (D-062), совместимость считается по уровням автомобиля. Сейчас администратор ведёт марки, модели, поколения, двигатели и модификации только запросами к API, а большой импорт загружает через `curl`.

Задача даёт экраны админки для справочника автомобилей и импорта файлом. Попутно убирает ограничение TASK-035: выпадающие списки брендов и автомобилей показывали только первые 100 записей.

## Требования

### 1. Справочник автомобилей (A-CAR-01)

- **Навигация по иерархии:** марки → модели марки → поколения модели (с годами) → модификации поколения. Хлебные крошки, адреса переживают перезагрузку.
- **На каждом уровне:**
  - список с поиском (`q`) и отбором по статусу, «Всего N», подгрузка;
  - создание, правка с версией, архив и восстановление;
  - число детей («моделей: 6», «модификаций: 4») — если сервер не даёт, добавить аддитивно.
- **Марки** — название и написания («Джили», «GEELY Auto»). **Модели** — перенос к другой марке.
- **Поколения** — название, годы «с … по …» (по — необязательно, «по наст. время»).
- **Модификации** — кузов, двигатель (выбор с поиском по коду), КПП, привод, годы в пределах поколения, рынок. Годы вне поколения — ошибка у поля словами.
- **Двигатели** — отдельный список: код, топливо, объём, мощность; где используется (число модификаций).
- **Справочные списки** (кузов, КПП, привод, топливо): код, названия kk/ru/en вручную (автоперевода нет), порядок, архив.
- **Ошибки сервера словами у нужного поля:**
  - дубль — «Такая марка уже есть · Открыть»;
  - конфликт версий — «Эти данные только что изменил {кто}. Обновите страницу», введённое не теряется;
  - восстановление под архивным родителем — «Сначала восстановите марку {название}».
- **Архив марки** прячет её модели от клиентов, не меняя их статуса (поведение сервера). Подтверждение говорит об этом: «Модели марки (N) пропадут из выбора автомобиля в приложении».

### 2. Импорт (A-CAR-02)

- **«Скачать шаблон»** — CSV из сервера, с описанием колонок и допустимыми значениями списков на экране рядом.
- **Загрузка файла** (CSV UTF-8). Ошибки файла словами по `reason`:
  - «Это не CSV — сохраните таблицу как CSV UTF-8» (для `.xlsx`);
  - неверная кодировка, пустой, нет строк, повреждён, нет колонок, лишние или повторяющиеся колонки, слишком много строк;
  - слишком большой файл.
  
  Тот же файл повторно — «Этот файл уже загружали {когда}» со ссылкой на прошлый импорт.
- **Отчёт до применения:**
  - пока сервер разбирает — ожидание без мигания, обновление само;
  - «Добавится N, обновится M, без изменений K, ошибок L»;
  - список ошибочных строк — номер строки как в таблице, причины словами;
  - новые марки, модели, поколения, двигатели с первой строкой;
  - все строки с отбором по плану.
  
  **До «Применить» в справочнике ничего не меняется — сказать это на экране.**
- **«Применить»** — подтверждение с числами → ожидание → итог:
  - создано, обновлено, без изменений, отклонено;
  - **«Решено иначе, чем в отчёте» (`differsFromReport`)** — с причинами по строкам. Такое бывает, если справочник изменили вручную после отчёта.
  
  Повторное применение невозможно, кнопки нет.
- **«Отменить»** импорт до применения.
- **История импортов** — кто загрузил и применил, когда, итог; зависший дольше срока — «прервался по времени».

### 3. Поиск вместо «первых 100»

- **Выбор автомобиля** во вкладке «Совместимость» карточки позиции (TASK-035) — марка, модель, поколение, двигатель — **с поиском по серверу**, а не из первых 100.
- **Бренд** в отборе «Позиций» и в форме позиции — тоже с поиском.
- **Один компонент «выбор с поиском»** для всех этих мест: поиск после 1–2 символов, без мигания (D-069), клавиатура (стрелки, Enter, Esc).

## Бизнес-правила

- Все проверки на сервере: уникальность, годы, согласованность уровней, архив родителя, разбор файла. Админка показывает ответ.
- Импорт ничего не меняет до «Применить». Применение — один раз.
- Названия справочных списков kk/ru/en вводит человек (автоперевода нет — ARCHITECTURE 4.24).
- Изменения справочника автомобилей видны в приложении не позже чем через минуту (`max-age=60`).

## Edge cases

- Файл на 10 000 строк — отчёт и применение не вешают страницу, ожидание показывает ход, если сервер его даёт.
- Импорт применили, пока второй администратор открыл тот же отчёт, — у второго «Импорт уже применён {кем}».
- Модификация, у которой двигатель в архиве, — видна с пометкой, правка не теряет двигатель молча.
- Длинные списки модификаций (десятки на поколение) — таблица без горизонтальной прокрутки на 1024.
- Поиск в выборе с поиском на казахском и латиницей («Джили» → Geely по написанию).
