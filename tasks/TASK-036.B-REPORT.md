## Technical Decisions
- **Отмена — своё действие и свой статус** (`cancelled_by_admin`, а не `cancelled_by_user`, чтобы никто не прочёл «Клиент отменил»); из «Создана / Принята / Готова» — истёкшую заявку решает «Закрыть без кода»; без W-04 (его текст «Клиент отменил заявку») и без новых шаблонов (I586).
- **Осознанное изменение контракта** — новый статус неизбежно попадает в `oneOf` ответов сканера кабинета (`oasdiff` считает это ломающим, известная особенность TASK-033); оба маршрута вызывает только кабинет, выкатываемый вместе с API; коммит 9fc8549 несёт трейлер `Contract-Breaking-Change` с обоснованием (I587). Остальное — аддитивно; `phone` выдачи доступа стал необязательным (ослабление запроса).
- **Номера скрывает сервер** в том же поле `phone` (схема — строка с описанием); раскрытие — отдельный POST с записью в журнал без номера (I588).
- **Пользователи — модуль без своих таблиц**; «кто пользователь» — одно условие для списка и поиска; клубный доступ — `ClubAccess.statesOf` и SQL-двойник `clubAccessUntil`; сессии — только приложения (I589, I590).
- **Поиск** — один разбор `readAdminQuery` в домене и правила списков модулей (I591).
- **Имена журнала** — `AuditNames` читает колонки названий таблиц других модулей: сознательное исключение (подпись к строке журнала, только чтение), записано в I592. Словарь полей и значений — один, в админке, с тестом.
- Всё внесено в `ARCHITECTURE.md` 4.57.

1. В шапке «1028» (или номер свежей заявки) → Enter — открывается заявка.
