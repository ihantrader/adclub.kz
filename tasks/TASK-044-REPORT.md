## Technical Decisions
Всё записано в `ARCHITECTURE.md` 4.64.

- **I656–I658 — одна предобработка, две формы текста.** «Текст» — для показа, «ключ» — для сравнения, с казахскими буквами, сложенными в русские. Тот же ключ считает база (`search_key`); интеграционный тест сверяет его с доменным.
- **I659 — текстовая ветка: кандидатов выбирает база, решает домен.** База отбирает кандидатов по началу слова (индекс `pg_trgm`, до 5 000). Совпадение по всем вариантам определяет `matchSearchDocuments`: точное, частичное или по своим текстам позиции. Так соответствие одно и тестируется без базы.
- **I660 — исправление слова (`pg_trgm.similarity` ≥ 0,4).** Включается, только когда ни один вариант ничего не нашёл. Пример задачи «лjkjlrb» раскладкой не объясняется: первая буква — клавиша K, а не R. Его даёт исправление «лолодки» → «колодки», и на экране «Показаны результаты по «колодки»».
- **I662 — показ только функциями каталога, без копий:** `visibleOffers`/`shownOffers`, `offersInReach`, `CompatibilityEvaluator` + `listed`, `summarize`, `describeListItems`. Поставщика в ответе поиска нет вовсе.
- **I663 — порядок `searchRankKey`:** артикул, затем точное, затем частичное. Внутри уровня — сначала в городе, потом по своему названию, потом дешевле, потом id.
- **I664 — предел частоты — существующие `catalog_read_per_ip`/`catalog_read_per_account`, своих настроек нет.** Подсказки при вводе — тот же маршрут с `limit=5`.
- **I666 — поиск админки и кабинета.** Название ищется как раньше или по ключу любого варианта запроса. Контракт и ранжирование этих поисков не менялись.

## Known Issues / Risks
- **Опечатки.** Исправление слова — только когда варианты не нашли ничего. Опечатка в запросе, который частично что-то нашёл, не исправляется. Полная устойчивость к опечаткам и ранжирование — TASK-045 (Meilisearch).
- **Локаль базы.** `pg_trgm.similarity` для кириллицы зависит от того, что локаль базы — UTF-8 (в Docker `postgres:16` — `en_US.utf8`). Ключ `search_key` от локали не зависит.
- **Расширение.** Миграция ставит `pg_trgm` (доверенное расширение). На управляемом PostgreSQL Servercore у владельца базы должно быть право `CREATE` на базе.
- **Масштаб.** Текстовая ветка без индекса по категориям и брендам: при очень общем запросе («тормоза») в кандидаты попадают все позиции узла, но не больше 5 000. До TASK-045 этого достаточно.
- **Dev-данные.** В dev-базе остались тестовые учётные записи `+77471119944` (пользователь «Тест Поиск») и `+77471119955` (администратор со вторым фактором).
