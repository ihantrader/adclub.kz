# TASK-044 — Поиск: предобработка запроса, точный артикул, экран поиска

Модель: Opus 5.5, High

## Цель

В приложении нет поиска: найти деталь можно только через категории. По решению Product Owner (11.10.2026) этап C продолжается поиском (EPIC-15), в две задачи:
- **TASK-044** — предобработка запроса (раскладка, транслитерация, синонимы), точный поиск по артикулу, текстовый поиск на PostgreSQL и экран поиска M-CAT-04;
- **TASK-045** — поисковый индекс Meilisearch: опечатки, фасеты, сверка, проверка качества на наборе фраз.

После этой задачи владелец Coolray вводит:

- «лjkjlrb» — видит то же, что по «колодки»;
- «brake pads» — то же.

## Требования

### 1. Предобработка запроса — домен, одна для всех

- **Чистые функции в `packages/domain`:**
  - нормализация: trim, регистр, `ё→е`, дефисы и пробелы;
  - признак «похоже на артикул» по правилу 10.2;
  - **раскладка:** русская ↔ английская ↔ казахская («лjkjlrb» → «колодки», «rjkjlrb» → «колодки», «ыеще» → «stop»);
  - **транслитерация** латиница ↔ кириллица («kolodki» → «колодки»);
  - набор вариантов запроса — не больше 4, без дублей.
  
  Юнит-тесты на таблице примеров, включая казахские буквы (ә ғ қ ң ө ұ ү һ і).
- **Применить ту же предобработку** в поиске позиции для поставщика и в поиске админки, где это улучшает результат без изменения их контракта. Решение агента — записать.

### 2. Синонимы — данные

- Таблица `item_search_synonym`: синоним позиции или категории, язык необязателен, текст; уникальность по нормализованному тексту в пределах позиции или категории.
- **Администратор** ведёт синонимы:
  - в «Справочнике» админки — вкладка позиции и поле категории, простым списком «добавить / убрать»;
  - маршруты `/admin/catalog/…` с журналом.
- **Dev-заполнение:** синонимы для примерного дерева («колодки», «тормозные колодки», «brake pads», «тежегіш қалыптары»; «масло», «моторное масло», «engine oil», «мотор майы» и т. п.).

### 3. Поиск для пользователя — сервер

- **`GET /catalog/search`** — гость и любая сессия, как каталог:
  - запрос `q` (от 2 знаков; короче — 400);
  - город;
  - автомобиль параметрами, как в списке подкатегории;
  - язык;
  - страница — курсор или `limit`.
- **Ветка артикула:** точное совпадение `article_norm` позиций и `supplier_sku` видимых предложений — первым блоком «по артикулу».
- **Текстовая ветка на PostgreSQL** (до Meilisearch в TASK-045):
  - по всем вариантам запроса;
  - названия позиций на kk/ru/en, бренд и его написания, названия категорий, синонимы;
  - похожесть — `pg_trgm` или иной стандартный способ PostgreSQL, решение агента; учесть опечатку в 1–2 буквы, если это даётся без большой цены, иначе — честно оставить опечатки TASK-045.
- **Выдача:**
  - только то, что пользователь мог бы увидеть в каталоге: позиции с видимыми предложениями (`shownOffers`), услуги — только в городе;
  - совместимость с автомобилем по D-029 через `CompatibilityEvaluator` — «не подходит» из результатов пропадает, «уточните параметр» — с отметкой;
  - строки как в M-CAT-02 (тот же код сводки предложений);
  - подсказки категорий (до 3);
  - признак «использован другой вариант запроса» и сам вариант — для T-CAT-08.
- **Ранжирование:** артикул → точное совпадение названия или синонима → частичное; товары с предложениями в выбранном городе выше. Порядок — одна функция, записать.
- **Предел частоты** — по образцу каталога (`catalog_read_*` или свой).
- **Кэш** — как у каталога: гость — `public, max-age=60`, сессия — `private, no-store`.

### 4. Приложение — M-CAT-04

- **Вход в поиск** — строка поиска на главной каталога и в списках (решение агента по месту, без перекрытия переключателей автомобиля и города).
- **До ввода:** недавние запросы с устройства (до 10, «Очистить»), хранятся на устройстве.
- **Ввод:** подсказки после паузы — артикул первым, категории, позиции; Enter или «Найти» — результаты.
- **Результаты** — строки M-CAT-02 с отметкой совместимости, подгрузка страниц; T-CAT-08, если сработал другой вариант запроса.
- **Ничего не найдено** — «Ничего не нашли по „…“» и советы: проверьте раскладку, попробуйте артикул или категорию. Замена «Искать без фильтра по автомобилю» (D-062): **«Искать для другого автомобиля из гаража»** — переключатель автомобиля в шапке. Решение агента; записать и описать в отчёте для Product Owner.
- **Без сети** — «Нужна сеть».
- **Тексты** kk/ru/en.

## Бизнес-правила

- Поиск не показывает того, чего не показал бы каталог: правило витрины, видимость поставщика, совместимость, город для услуг — те же функции, без копий.
- Поставщик гостю не называется.
- Запросы пользователей в журнал действий не пишутся. Лог — без текста запроса, если в нём может быть номер телефона (санитайзер).

## Edge cases

- Запрос — номер телефона или e-mail: ищется как текст, в логах маска.
- Артикул с пробелами, дефисами, точками и в нижнем регистре — один результат.
- Запрос из одной буквы — 400; из двух — работает.
- Синоним совпадает с названием другой позиции — обе в выдаче, порядок по правилу.
- Длинный запрос (200 знаков) — без ошибки сервера, предел длины — 400.
- Услуга без выбранного города — подсказка выбрать город, как в каталоге.
- Казахский запрос, набранный в русской раскладке.

## Не входит

- Meilisearch, фасеты, опечатки «из коробки», outbox, ночная сверка, тест качества на наборе фраз — TASK-045.
- Голос и фото как вход в поиск — этап D.
- «Спросить AI Pilot» — этап D.
