# TASK REPORT — TASK-061

## Status

## Result
Регламент ТО — данные справочника. Администратор в «Справочник → Регламенты ТО» заводит план для марки / модели / поколения / двигателя вручную или получает черновик ИИ (элементы «предложено ИИ», элемент с несуществующей подкатегорией — без правила, с пометкой `unmapped`), подтверждает элементы по одному или все сразу, задаёт правила подбора (подкатегория + условия её фильтров или конкретные позиции), активирует план (сервер отказывает с причинами по элементам или со ссылкой на действующий план области), копирует план на соседнюю область, проверяет «что положено и что продаётся» на автомобиле. Клиенты и будущий помощник получают `GET /maintenance/plan`: самый конкретный действующий план, положенные элементы по пробегу / коду ТО / сроку и для каждого — сколько позиций по правилу продаётся под этот автомобиль и город, посчитанное тем же кодом, что список подкатегории каталога.
