# TASK REPORT — TASK-062

## Status

## Result
Сервер помощника AI Pilot работает end-to-end. Человек (гость по `deviceId` или вошедший) пишет `POST /assistant/messages`. Сервер прогоняет ход: модель может только искать инструментами по каталогу и закончить ход вопросом (`ask_user`) или ответом (`propose`). Ответ — текст модели (только текст, вычищенный от ссылок, телефонов и «диагноза») и карточки, которые сервер собирает сам из каталога.

- **Grounding.** Показывается только позиция, которую вернул инструмент этого диалога и которая сейчас продаётся под этот автомобиль и город.
- **Симптом.** Оговорку T-AI-01 и карточку диагностики города добавляет сервер.
- **ТО.** Группы с итогом «от N ₸», «на платформе пока нет» и предложением обновить пробег.
- **Не по теме.** Фиксированный отказ.
- **Лимиты.** Гостю — пробные диалоги, вошедшему — дневные, считаются один раз на диалог. Отказ провайдера ничего не тратит. Есть пределы по адресу и по учётной записи, бюджеты и сигнал администратору.
- **Хранение.** Диалоги, сообщения и вызовы инструментов хранятся с обезличиванием по сроку и каскадом от учётной записи.
- **Жалоба на ответ.** В админке есть раздел «Помощник»: список, карточка диалога с инструментами и стоимостью, «Решить…», карточка на главной, журнал.
- **Замер моделей.** Набор из 34 сценариев и команда `ai:eval:assistant`.

## Technical Decisions
Всё внесено в ARCHITECTURE 4.85.
- **Намерение — поле закрывающего инструмента**, а не отдельный вызов (I956). Замер подтвердил ≥ 90 % у выбранной модели.
- **`tool_choice: "auto"`, а не `"required"`.** Gemini через OpenRouter отвечает 400 на `"required"` со схемой поиска (найдено бисекцией запросов). Модели, ответившей просто текстом, конвейер один раз напоминает закрыть ход (I957).
- **Переносимая JSON Schema инструментов** — без `pattern`, `format` и `additionalProperties` (Gemini отвергает весь запрос). Строгую проверку аргументов делает zod на сервере (I958).
- **Запасная модель помощника** пробуется и после `no_private_provider` и `invalid_output` (I959).
- **История прошлых ходов — в протоколе инструментов.** Закрывающий вызов и его результат передаются как вызовы, а не строками: Gemini копировала наш строковый формат в текст вместо вызова инструмента. Это показал первый прогон замера (I965).
- **Лимит диалогов** считается с первым ходом, дошедшим до модели, и возвращается при отказе провайдера. Новый диалог при исчерпанном лимите отклоняется до открытия, чтобы текущий диалог не закрылся (I967).
- **Новый диалог закрывает прежние** («хранится только текущий диалог»). Стоимость закрытого идёт в гистограмму (I966).

## Deviations
- **Умолчание `assistant_symptom_disclaimer` изменено** на текст SCREENS T-AI-01 («Это не диагноз. Точную причину определит сервис.»). Прежнее умолчание TASK-007 расходилось с SCREENS и с «Что должно реально работать».

- **`ai_job_id` → `ai_job_ids uuid[]`.** Ход — несколько шагов модели, у каждого своя запись `ai_job`.
- **Сценарный ИИ не разыгрывает вопрос о двигателе.** Edge case «автомобиль без двигателя» поддержан инструментом: к результату поиска приложены двигатели модели, `engineId` проверяется. Но сценарий в тестовом ИИ этот путь не проходит; в замере есть сценарий `engine-unknown`.

## Known Issues / Risks
- **Остаточные промахи модели (≈ 3–6 % сценариев).** Подмена «не того» товара при пустом поиске («нет щёток — вот масла»), вопрос вместо отказа не по теме у запасной модели. Сервер не пускает на экран ничего, что не продаётся под автомобиль, но не судит, «то ли» это, что просили.
- **Тест «Два хода одновременно»** опирается на задержку тестового провайдера 600 мс.
- **Метрики хода и grounding** — счётчики процесса API (не из базы).
- **Отказы модели** из-за кривого ответа в замере считаются ошибкой. Порог «0 ошибок» — строже D-058.
