## Technical Decisions
- **Механизм предела — свойство маршрута в контракте** (`waitsForModel`), а не список в приложении. Список маршрутов один на клиент API и на обёртку `fetch` приложения. Новый маршрут к модели получает предел, если пометить его в контракте.
- **Граница сервера закреплена кодом, а не только настройкой.**
  - Предел клиента должен быть «не меньше `assistant_turn_seconds` + запас», а настройка допускала 300 с. Поэтому её верх снижен до 75 с.
  - Фото получили явный срок 60 с: раньше основная и запасная модель могли занять по 60 с.
  - Хранимое значение настройки выше 75 перестанет приниматься. В dev и на staging стоит умолчание 45.
- **Без повторов:** обрыв и таймаут не повторяются нигде. Повтор после `ACCESS_TOKEN_EXPIRED` оставлен: этот 401 отдаёт охрана сессии до всякой работы и до лимитов, хода нет.
- **Открытие после обрыва — ключ, а не «перечитать последний диалог».** «Последний» мог быть сознательно оставлен «Новым диалогом». Ключ отвечает одним запросом и без нового маршрута; контракт меняется только аддитивно.
- Всё внесено в ARCHITECTURE 4.86 (I990–I993).
