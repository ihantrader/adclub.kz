## Technical Decisions
Внесены в ARCHITECTURE 4.95, I1165–I1169.
- **Обход по индексу страницами, а не предварительный отбор и не хранимый признак.** Любой отбор одним запросом в худшем случае читает всех кандидатов до первого видимого. Страница читает ровно 1000 строк индекса. Курсор живёт один вызов, между запусками ничего не хранится.
- **Правило витрины — только `shownOffers()`,** предварительного отбора нет вовсе.
- **Порядок ослаблен (I1167):** «больше предложений — раньше» действует внутри первых 200 позиций на витрине в порядке ожидания (не искали → искали давнее → старшая позиция), а не по всему каталогу.

## Замеры (AC-2)
