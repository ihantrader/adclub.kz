## Technical Decisions
- Не `vitest --shard`: он делит по числу и размеру файлов, а не по времени. Один файл (`jobs`, ~4 мин) тяжелее всех остальных вместе по 3, поэтому нужна раздача по весу. Решение — своя раздача + проверка полноты. В `ARCHITECTURE.md` не вносилось: это устройство CI и тестов, не продукта (если нужно — добавлю отдельным пунктом).
- 5 частей: часть 1 — только `jobs` (~4 мин), остальные 4 части заканчиваются за 2–3 мин. Меньше частей время не улучшит (его держит `jobs`), больше — не ускорит.
- Docker-образы не кэшируются: загрузка образов не видна среди самых долгих шагов (самый долгий шаг, кроме тестов, — 8 с), кэш не окупится.
- Сверка списков вынесена во «вторую копию» списка, а не в разбор исходника теста: списки стали данными, тесты их импортируют — расхождение между тестом и проверкой невозможно.
